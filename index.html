02.1

Fetch

1st Place Overall · CSI Hacks

Co-founder · hardware lead

A trash-can robot that drives itself to whoever calls it, localizing with AprilTags instead of lidar. Built in ~8 hours; I did the CAD, electronics, and hardware.

Pi 4 + Arduino Uno R4 / 4× NEMA 17 mecanum / AprilTag + QR nav / ultrasonic e-stop

  • Mecanum Kinematics
  • AprilTag Localization
  • CAD
  • Embedded Electronics
GitHub ↗ Devpost ↗
02.2

Ceres

2nd Place · Berkeley Robotics Hackathon

Co-founder · hardware lead

An affordable crop-monitoring robot that spots diseased leaves with a VLM we trained and probes soil with a rack-and-pinion sensor arm. Built in ~7 hours; I did the hardware.

Pi 4 + Arduino Mega / 4WD, dual L298N / MG996R pan-tilt camera / STEMMA soil probe

  • Custom VLM
  • Rack & Pinion
  • Pan-Tilt Control
  • Soil Sensing
GitHub ↗ Demo ↗
02.3

Street Sweeper

2nd Place · Milpitas Hacks

Team of 4 · hardware & electronics

A trash-collecting robot you program by typing commands, so driving it doubles as a coding lesson.

ESP32 / L298N two-wheel drive / camera-guided intake

  • ESP32
  • Motor Drivers
  • Computer Vision
  • Command Parsing
GitHub ↗
02.4

HocDiuTempusSumpsit robotic arm

Solo build

3D-printed · Bluetooth controlled

A 4-bar linkage arm with a three-finger helical-gear gripper. When the elbow couldn't hold the load, I reworked the joint geometry instead of buying a bigger servo.

2× ESP-WROOM-32 + PCA9685 over BLE / MG996R, SG90, A330 servos

  • 4-Bar Linkage
  • Gear Design
  • BLE
  • 3D Printing
